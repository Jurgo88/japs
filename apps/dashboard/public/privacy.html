Privacy

Last updated: 16 October 2026

JAPS (Just Another Portfolio Site) turns your GitHub repositories and Netlify sites into a portfolio. This page says what JAPS stores, where it goes and how to delete it. JAPS is run by Juraj Paluš as a personal project; the source code is public at github.com/Jurgo88/japs.

What JAPS stores

  • Your GitHub profile: user id, username, name and avatar URL, from signing in.
  • Access tokens for GitHub, Netlify and Cloudflare (if you connect them), and an AI key if you add your own. They are encrypted (AES-GCM) before they are stored, used only on the server, and never sent back to your browser.
  • What JAPS finds in your accounts: the list of your Netlify sites, Cloudflare Pages projects and GitHub repositories, and for the projects you pick, facts such as languages, frameworks, dates, commit counts and README excerpts.
  • Your portfolio: the profile texts, settings and generated project texts you edit in JAPS.
  • Screenshots (desktop and mobile) of the live sites of the projects your portfolio shows, taken with Cloudflare's browser service. They are only visible to you until you publish.
  • Usage: how many AI generations and tokens you used per month, to apply the free limit.

GitHub access is read-only. JAPS sees private repositories only where you install the JAPS GitHub App on them.

Who else receives data

  • The AI provider. To write project texts, JAPS sends the facts of the projects you picked (including README excerpts, also from private repositories) to OpenAI, or to the provider of your own key if you added one. Nothing is sent for projects you didn't pick. A project marked “anonymize” is sent without its name, description, URLs or README. The provider handles the data under its API terms.
  • Cloudflare hosts JAPS (Workers, D1 database) and processes requests and stored data on JAPS's behalf.
  • GitHub, Netlify and Cloudflare receive the requests JAPS makes with your tokens, as they would from any app you authorize.
  • GitHub Actions builds your site when you press Publish: it receives the portfolio you are about to publish (texts and screenshots) and nothing else. Your Netlify token stays with JAPS. The build log is public and shows only counts, never your content.

JAPS has no ads, no analytics and no tracking, and does not sell or share data with anyone else.

Cookies

Two cookies, both needed for signing in: a session cookie (30 days, only a random value; the server stores its hash) and a short-lived cookie that protects the GitHub and Netlify sign-in from forgery (10 minutes).

How long, and how to delete it

Data is kept while you have an account. Profile → Delete account deletes your account and everything listed above at once and revokes JAPS's GitHub and Cloudflare authorizations. To be thorough, also remove the app on GitHub → Applications and in Netlify under User settings → Applications, and on Cloudflare under Profile → Access management → OAuth authorizations. A portfolio you already published stays on your Netlify until you delete that site there.

Your rights

You can see and change your data in the editor, and delete it at any time. For any other question or request (for example under the GDPR), open an issue at github.com/Jurgo88/japs/issues.
